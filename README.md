# 물과 바람의 방정식

교사 연수용 인터랙티브 페이지입니다. 나비에-스토크스 방정식을 '물과 바람의 방정식'으로 소개하고, 대표 장면 두 개를 3D로 보여 줍니다.

각 장면은 같은 상황을 두 세상으로 나란히 보여 줍니다. 왼쪽(휴대폰은 위쪽)은 방정식이 없을 때, 오른쪽(아래쪽)은 있을 때입니다.

- 물 · 기름 유출: 방정식이 있으면 해류를 계산해 기름이 닿을 해안을 미리 알고 오일펜스로 막습니다. 없으면 기름이 해변과 마을을 덮칩니다.
- 바람 · 태풍: 방정식이 있으면 사흘 전부터 진로를 알고 배를 항구로 돌려보냅니다. 없으면 바다에 남은 배가 피해를 입습니다.

`index.html` 파일 하나로 되어 있어 브라우저로 바로 열 수 있습니다. 3D 장면(three.js)과 글꼴은 인터넷에서 불러옵니다.
