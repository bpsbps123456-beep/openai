# 물과 바람의 방정식

교사 연수용 인터랙티브 페이지입니다. 나비에-스토크스 방정식이 무엇이고 어디에 쓰이는지, 2026년 9월 OpenAI가 발표한 결과가 정확히 무엇인지를 설명합니다.

- 물감 수조: 브라우저에서 실시간으로 방정식을 풀어 보여 주는 2D 시뮬레이션
- 방정식 실험실: 관성, 압력, 점성, 외력 항을 하나씩 켜고 끄며 차이를 보기
- 3D 가상 풍동: 공과 유선형 물체 주위의 공기 흐름
- 소용돌이 늘이기: 난제의 핵심인 '폭발(blow-up)' 개념을 보여 주는 3D 애니메이션

`index.html` 파일 하나로 되어 있어 브라우저로 바로 열 수 있습니다. 3D 장면(three.js)과 글꼴은 인터넷에서 불러옵니다.
