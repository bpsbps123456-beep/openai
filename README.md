# 물과 바람의 방정식

교사 연수용 인터랙티브 페이지입니다. 나비에-스토크스 방정식을 '물과 바람의 방정식'으로 소개하고, 이 식이 생활 어디에 쓰이는지 보여 줍니다.

화면 오른쪽 아래의 스위치 하나로 페이지 전체의 방정식을 켜고 끌 수 있습니다. 장면마다 방정식이 있을 때와 없을 때를 나란히 비교합니다.

- 물감 수조: 방정식을 끄면 물감이 칠한 자리에 멈춥니다
- 물 · 바다: 기름띠가 해류를 타고 어느 해안에 닿을지 예측
- 물 · 혈관: 좁아진 혈관에서 피가 얼마나 빨라지는지
- 바람 · 교실: 창문 닫기, 한쪽만 열기, 맞통풍 비교
- 바람 · 태풍: 예상 경로가 있을 때와 없을 때
- 바람 · 자동차·기차: 3D 가상 풍동에서 공 모양과 물방울 모양 비교
- 바람 · 축구: 차기 전에 공이 휘는 길을 미리 보는 프리킥

`index.html` 파일 하나로 되어 있어 브라우저로 바로 열 수 있습니다. 3D 장면(three.js)과 글꼴은 인터넷에서 불러옵니다.
